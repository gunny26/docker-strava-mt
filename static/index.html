Um eine Aktivität hinzuzufügen, benötigst du die Activity ID von Strava.

Du findest diese ID ganz einfach in der URL, wenn du eine Aktivität im Browser öffnest:

https://www.strava.com/activities/1234567890

Kopiere einfach die Zahl am Ende der URL und füge sie rechts in das Feld "Activity ID" ein.

3. Datenerfassung auf dieser Website

Server-Log-Dateien

Der Provider der Seiten erhebt und speichert automatisch Informationen in so genannten Server-Log-Dateien, die Ihr Browser automatisch an uns übermittelt. Dies sind:

  • Browsertyp und Browserversion
  • verwendetes Betriebssystem
  • Referrer URL
  • Hostname des zugreifenden Rechners
  • Uhrzeit der Serveranfrage
  • IP-Adresse

Eine Zusammenführung dieser Daten mit anderen Datenquellen wird nicht vorgenommen. Die Erfassung dieser Daten erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO. Der Websitebetreiber hat ein berechtigtes Interesse an der technisch fehlerfreien Darstellung und der Optimierung seiner Website – hierzu müssen die Server-Log-Files erfasst werden.

Lokale Speicherung (Local Storage)

Diese Anwendung nutzt den lokalen Speicher (Local Storage) Ihres Browsers, um bestimmte Einstellungen und Daten auf Ihrem Endgerät zu speichern. Dies umfasst:

  • Ihre bevorzugte Theme-Einstellung (Hell/Dunkel)
  • Gespeicherte Sets von Strava-Aktivitäten (Activity IDs und Zuschnitt-Zeiten)

Diese Daten verbleiben ausschließlich auf Ihrem Endgerät und werden nicht an unsere Server übertragen. Sie können diese Daten jederzeit löschen, indem Sie die Browserdaten (Cache/Local Storage) in den Einstellungen Ihres Browsers leeren.

4. Nutzung der Strava API

Diese Anwendung bietet die Möglichkeit, sich mit Ihrem Strava-Konto zu verbinden, um Aktivitätsdaten (wie GPS-Tracks, Höhenmeter, Herzfrequenz, Geschwindigkeit) abzurufen und zu visualisieren. Die Authentifizierung erfolgt über das OAuth-Verfahren direkt bei Strava.

  • Zugriffstoken: Wenn Sie sich anmelden, erhält diese Anwendung ein temporäres Zugriffstoken von Strava. Dieses Token wird in der URL Ihres Browsers gehalten und genutzt, um in Ihrem Auftrag Daten von der Strava API abzurufen.
  • Datenspeicherung: Wir speichern Ihre Strava-Aktivitätsdaten nicht dauerhaft auf unseren Servern. Die Daten werden lediglich für den Moment der Sitzung abgerufen, um sie in Ihrem Browser darzustellen.
  • Widerruf: Sie können den Zugriff dieser Anwendung auf Ihr Strava-Konto jederzeit in den Einstellungen Ihres Strava-Profils unter "Meine Apps" widerrufen.

Weitere Informationen zum Datenschutz bei Strava finden Sie in der Datenschutzerklärung von Strava.

Diese Seite nutzt über eine API Kartendienste von OpenStreetMap (OSM) und OpenTopoMap. Zur Nutzung der Funktionen dieser Kartendienste ist es notwendig, Ihre IP-Adresse zu speichern. Diese Informationen werden in der Regel an einen Server der jeweiligen Anbieter übertragen und dort gespeichert. Der Anbieter dieser Seite hat keinen Einfluss auf diese Datenübertragung. Die Nutzung erfolgt im Interesse einer ansprechenden Darstellung unserer Online-Angebote. Dies stellt ein berechtigtes Interesse im Sinne von Art. 6 Abs. 1 lit. f DSGVO dar.

Content Delivery Networks (CDNs)

Wir binden externe Skripte (wie Chart.js und Leaflet) über Content Delivery Networks (z.B. jsdelivr.net, unpkg.com) ein. Wenn Sie unsere Seite aufrufen, lädt Ihr Browser die benötigten Dateien von diesen Servern, um sie korrekt anzuzeigen. Dabei wird Ihre IP-Adresse an die Betreiber dieser CDNs übertragen. Dies erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO zur Gewährleistung einer sicheren und effizienten Bereitstellung unserer Website.
